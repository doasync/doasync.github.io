# Безопасность проекта

## Важные замечания по безопасности

### ⚠️ Конфиденциальная информация

Этот проект был очищен от всей конфиденциальной информации для безопасного публичного распространения. Все чувствительные данные заменены на плейсхолдеры:

- **API ключи**: `YOUR_VOIDAI_API_KEY_HERE`
- **Токены ботов**: `YOUR_TELEGRAM_BOT_TOKEN_HERE`
- **Секретные ключи**: `YOUR_SECRET_KEY_HERE`
- **ID пользователей**: `123456789`

### 🔒 Настройка безопасности

#### 1. Переменные окружения

**НИКОГДА** не коммитьте файл `.env` в Git! Используйте `.env.example` как шаблон:

```bash
# Скопируйте пример и заполните реальными данными
cp .env.example .env
```

#### 2. Генерация секретных ключей

Всегда генерируйте новые секретные ключи:

```bash
# Для SECRET_KEY
python -c "import secrets; print(secrets.token_hex(32))"

# Для других ключей используйте криптографически стойкие генераторы
```

#### 3. API ключи

- Получите реальные API ключи от соответствующих сервисов
- Ограничьте права доступа ключей до минимально необходимых
- Регулярно ротируйте ключи
- Мониторьте использование ключей

#### 4. База данных

- Используйте сильные пароли для продакшн БД
- Ограничьте сетевой доступ к БД
- Регулярно создавайте резервные копии
- Шифруйте чувствительные данные в БД

### 🛡️ Рекомендации по развертыванию

#### Для разработки:
- Используйте локальные переменные окружения
- Не используйте продакшн ключи в разработке
- Регулярно обновляйте зависимости

#### Для продакшна:
- Используйте HTTPS для всех соединений
- Настройте файрвол и ограничьте доступ
- Используйте reverse proxy (nginx/apache)
- Настройте мониторинг и логирование
- Регулярно обновляйте систему и зависимости

### 🚨 Что делать при компрометации

1. **Немедленно** отзовите скомпрометированные ключи
2. Сгенерируйте новые ключи и обновите конфигурацию
3. Проверьте логи на подозрительную активность
4. Уведомите пользователей при необходимости
5. Проведите аудит безопасности

### 📞 Контакты

При обнаружении уязвимостей безопасности:
- Создайте приватный issue в репозитории
- Опишите уязвимость и шаги для воспроизведения
- Дождитесь ответа перед публичным раскрытием

### 🔄 Регулярные проверки

Рекомендуется регулярно:
- Обновлять зависимости: `pip install --upgrade -r requirements.txt`
- Проверять уязвимости: `pip audit`
- Ротировать API ключи
- Проверять логи на подозрительную активность
- Делать резервные копии данных

---

**Помните**: Безопасность - это процесс, а не состояние. Регулярно пересматривайте и обновляйте меры безопасности.
